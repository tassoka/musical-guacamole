# Склад интернет-магазина

Веб-приложение «Склад» позволяет вести учёт товаров интернет-магазина: хранить карточки товаров, фиксировать остатки, отслеживать историю приходов и расходов, а также импортировать и экспортировать данные в Excel.

## Возможности

- таблица с быстрым редактированием основных полей товара (категория, наименование, оптовая цена, цена продажи, GTIN, дата поступления);
- кнопки `+` и `-` для оперативного увеличения или уменьшения остатков;
- автоматическое ведение истории изменений с датой и типом операции;
- добавление новых позиций через форму с автоматической датой поступления (значение можно изменить вручную);
- экспорт всех товаров в Excel и загрузка шаблона для импорта;
- импорт данных из Excel-файла (обновление существующих записей по наименованию или добавление новых);
- поиск по наименованию, фильтр по категории и удаление товаров непосредственно из списка;
- раздел «Поставщики» для загрузки прайс-листов по ссылке, сопоставления колонок и просмотра данных в таблицах, оформленных как основная страница склада.
- база данных SQLite (`inventory.db`) хранится в корне проекта.

## Быстрый старт

1. Установите зависимости и активируйте виртуальное окружение (опционально):

   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
   pip install -r requirements.txt
   ```

2. Инициализируйте базу и запустите приложение:

   ```bash
   flask --app app run
   ```

   или:

   ```bash
   python app.py
   ```

3. Перейдите в браузере по адресу [http://127.0.0.1:5000](http://127.0.0.1:5000) и начните работу.

## Импорт и экспорт

- **Шаблон для импорта**: нажмите «Скачать шаблон Excel», заполните столбцы (`Категория`, `Наименование`, `Опт`, `Цена продажи`, `Остаток`, `GTIN`, `Дата поступления`).
- **Импорт**: выберите заполненный файл в формате `.xlsx` и нажмите «Импортировать». Существующие товары обновляются по наименованию, новые добавляются автоматически.
- **Экспорт**: кнопка «Экспортировать в Excel» выгружает актуальный список товаров и их остатки.

## Парсинг прайс-листов поставщиков

1. Перейдите в раздел «Поставщики» через верхнее меню.
2. Нажмите «Добавить прайс-лист», укажите название и либо ссылку на Excel/Google Sheets, либо загрузите файл вручную (поддерживаются форматы `.xlsx` и `.xls`).
3. Нажмите «Загрузить таблицу», отметьте нужные листы и сопоставьте хотя бы колонку «Наименование». Колонки «Опт», «РРЦ» и «Остаток» можно указать по желанию, при необходимости задайте курсы пересчёта опта и РРЦ.
4. Сохраните обработчик — прайс-лист появится в виде карточки с таблицей, оформленной как основной склад (без категории и даты поступления); для каждого листа автоматически создаются подвкладки.
5. Для изменения источника, выбранных листов, сопоставления колонок или курсов воспользуйтесь кнопкой «Изменить» на карточке.
6. Данные обновляются автоматически, при необходимости можно воспользоваться кнопкой «Обновить» на карточке или общим обновлением сверху.

## Структура проекта

```

inventory.db       # Файл базы данных (создаётся автоматически при первом запуске)
requirements.txt   # Зависимости Python
static/            # Стили и сценарии интерфейса
templates/         # HTML-шаблоны
```

Приложение готово к развёртыванию на любом сервере с поддержкой Python 3.10+.
